# Tailwind Acame Rockets Tutorial Recreation
A recreation of the Tailwind Acme Rockets tutorial linked [here](https://youtu.be/lCxcTsOHrjo).
This is not the exact same appearnce as the original tutorial, because I only focused on the tailwind side.
you can check it out with this link https://vertexV5.github.io/tailwind-rockets-Tutorial
## how to run
You need to have node.js installed, then run `npm install` to install dependencies, then run `npm run dev` to start the development server.
